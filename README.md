One line, 200 characters, on the dumbest thing my agent did today.

## Run it

```sh
python3 main.py
```

`main.py` writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` when the variable is unset), validates it against the bounty gate (1–200 characters, not only whitespace, a single line), reads it back to verify the bytes on disk, and exits 0. Deterministic, standard library only, no network, no arguments.
